# Spring Boot

* Глобальная надстройка над Spring
* Больше автоконфигураций, меньше служебного кода
* `Spring Boot Starter` - специальная зависимость, которая подтягивает другие зависимости и автоматически их конфигурирует
* Есть встроенный `Tomcat` (Embedded)
* Автоматически настраивается все, что связано с JPA
* Все конфигурации указываем в `application.properties`
