# Архитектура проекта

* Домен - это модель предметной области, одна сущность. Есть операции, которые подразумевают использование домена:
  * Добавить/Удалить
  * Проверить существование
  * и т.д.

В этом случае используется связа контроллер-сервис домена-репозитрий домена

* Есть ситуации, когда бизнес-операция может использовать несколько доменов:
  * Получение всех заказов пользователя
    * Проверить существование пользователя - домен пользователя
    * Получить все заказы - домен заказов
* В этом случае делаем фасадный сервис, который использоует сервисы обоих доменов.
